⛏️ Idle Mining Empire

A 2D idle mining tycoon made in Unity: mine, sell, upgrade, automate, dig to the Core, Rebirth, and descend the endless Abyss.

The browser version hasn't been published yet. This page is replaced by the playable game as soon as a WebGL build is pushed.

To publish it (about 5 minutes):

  1. Open the project in Unity Hub with Unity 6 (with the WebGL Build Support module).
  2. In Unity's menu bar choose Idle Mining Empire > Build > WebGL. It builds into this docs folder.
  3. Commit and push. GitHub Actions deploys it here automatically.
